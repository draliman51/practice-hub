# Ali Family Practice Hub

Practice-exam platform for Mansour and Aleen (Knowledge City Schools): PIN login for each child, an admin panel for Dad, per-attempt analytics, answer review with explanations, and PDF exports.

## Structure

| Path | What it is |
|---|---|
| `index.html` | The whole app (single page). Exams and settings are embedded as a seed. |
| `data.json` | Seed data (exams, students, admin password). Used by the API until the first publish from the admin panel. |
| `api/data.js` | `GET` current exams/settings · `POST` publish from the admin panel |
| `api/results.js` | `GET` all results · `POST` one result · `DELETE` all (admin) |
| `pdf/` | Answer-key and student PDFs for every exam |

## Deploy on Vercel

1. Import this repository at <https://vercel.com/new> (Framework preset: **Other**). No build command, output directory `.` (root). Deploy.
2. **Enable server storage** (so results and exams sync across devices):
   Project → **Storage** → **Create database** → **Blob** → connect it to this project. Vercel adds `BLOB_READ_WRITE_TOKEN` automatically. Redeploy once.
3. Open the site. The admin panel shows **Server sync on** when storage works.

Without a Blob store the site still works per device: results stay on the child's device and can be sent to Dad as a results code (WhatsApp button).
